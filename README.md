# operaverse.com

Website for **Operaverse · Youth Performance Arcade**, a youth performance arcade in Singapore where Gen Alpha collect, build and perform Chinese Street Opera with artisans and opera troupes.

- `index.html`: the whole site in one file, with its CSS, JS and SVG drawings inline
- `fonts/`: Big Shoulders Display, Hanken Grotesk and Pixelify Sans (woff2)
- `assets/`: the Operaverse logo as a PNG (original) and as a traced SVG

Open `index.html` in a browser to view it. No build step is needed.
